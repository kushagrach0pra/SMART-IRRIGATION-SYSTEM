# SMART-IRRIGATION-SYSTEM

I developed a Smart Irrigation System using a Soil Moisture Sensor that monitors soil moisture in real time and automatically controls a water pump whenever the soil becomes dry. The system also displays the moisture status on an LCD, making it easy to monitor conditions while promoting efficient water usage and reducing manual intervention. It's a simple yet practical example of how embedded systems can be applied to solve real-world agricultural challenges.
